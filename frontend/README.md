# issueMatch Landing Page

A cinematic, developer-first landing page for issueMatch.

## Stack
- React
- Vite
- CSS
- No UI component library
- No animation framework

## Run locally

```bash
npm install
npm run dev
```

## Notes
- The hero uses the exact globe treatment from the supplied reference screenshot, cropped and blended into the dark background.
- The Open Source Initiative mark supplied in the design references is used as a scroll-driven marker in the history section.
- Satoshi is the intended brand font; the CSS uses it first and falls back to Inter/system fonts.
- The page is intentionally dependency-light.
